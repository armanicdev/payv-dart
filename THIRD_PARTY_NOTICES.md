## HarfBuzz — reference implementation used as ground truth

`test/fixtures/harfbuzz_golden.json` records glyph ids, clusters and positions
produced by [HarfBuzz](https://harfbuzz.github.io/) (© Behdad Esfahbod and
others, "Old MIT" licence) through the `uharfbuzz` Python bindings. The engine's
shaping order, its normalisation rounds and its treatment of transparent marks
follow HarfBuzz's documented behaviour deliberately: where `payv` and HarfBuzz
disagree, `payv` is considered wrong.

No HarfBuzz code is included in this package. The goldens are measurement
output, produced by `tool/gen_harfbuzz_corpus.py`, which is a developer tool and
is not required to build or use `payv`.

## fontTools — cross-check tooling

[fontTools](https://github.com/fonttools/fonttools) (MIT, © Just van Rossum,
Behdad Esfahbod and others) is used by `tool/gen_glyf_corpus.py` and by the

## zlib — algorithm and tuning constants

`lib/src/util/deflate.dart` is an independent Dart implementation of DEFLATE
(RFC 1951) and its zlib wrapper (RFC 1950). Its per-level tuning parameters and
its lazy-matching structure follow those of
[zlib](https://zlib.net/) (© 1995–2024 Jean-loup Gailly and Mark Adler, zlib
licence), which are the de-facto reference values for these algorithms. No zlib
source code is included.
